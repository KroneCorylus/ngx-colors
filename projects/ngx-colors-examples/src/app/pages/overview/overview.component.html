3 — Use

The ngxColorsTrigger directive turns any element into a trigger; <ngx-colors> is a premade swatch button. They can be combined or used separately.

No extra setup — the picker uses plain CSS animations, so you don't need provideAnimations() or BrowserAnimationsModule.
